About Me

Building clear, responsive websites.

I'm a junior front-end developer and website designer based in Cairo. I work with HTML, CSS and JavaScript to build responsive pages that are easy to read and easy to use on any screen.

Most of my recent work is in healthcare: dental clinics, a medical center and a foot clinic. I focus on what a visitor needs first — services, working hours, location and a quick way to reach the clinic — with Arabic and English layouts and light and dark themes where a project calls for them.

Two of these projects are unofficial concept prototypes, and I label them that way. I would rather show my work honestly than inflate it.

athr — Dental Clinic Concept

An unofficial design concept for a dental clinic website: calm editorial layout, Arabic and English, light and dark themes, and a WhatsApp contact request form.

Unofficial Concept Dental Clinic HTML · CSS · JS
View live site
Project Type

Unofficial design concept — dental clinic website. It is not the clinic's official site.

Problem

How can a dental clinic present its digital planning, clear treatment steps and easy contact on one calm page? This is a self-initiated concept, not a client request.

Approach

Arabic-first right-to-left layout with an English toggle and a light/dark theme switch. A short contact form opens WhatsApp with a ready-to-send message without storing data. The page is clearly labeled unofficial, and unconfirmed services are marked as such.

Result

A working single-page concept with an FAQ and public contact details. It is open about its status: it states that it does not represent the clinic and that all content needs the clinic's approval.

Technologies

HTML · CSS · JavaScript · Hosted on Vercel

El Yasmeen Dental Clinic — Concept

An unofficial sample site for a dental clinic in Helwan, built from public listings: services, doctor profile, map, working hours and quick call and WhatsApp actions.

Unofficial Concept Dental Clinic HTML · CSS · JS
View live site
Project Type

Unofficial sample — dental clinic website. Details are marked as pending the clinic's confirmation.

Problem

A clinic's details are often scattered across directory and map listings. This sample explores gathering services, doctor profile, location and hours on one clear page. It is self-initiated, not a client request.

Approach

Right-to-left Arabic layout with a light/dark theme toggle, a services section, a doctor profile, an embedded map, and call and WhatsApp buttons. Information from public sources is flagged as needing confirmation, and a persistent badge marks the page as an unofficial sample.

Result

A single-page sample that keeps contact actions within reach and is transparent about which details are unverified.

Technologies

HTML · CSS · JavaScript · Google Maps embed · Hosted on Vercel

Aster Medical Center

A multi-page Arabic website for a dental and medical center in Mokattam, with a page for each service, a blog, an English version and quick call and WhatsApp actions.

Medical Center AR / EN HTML · CSS · JS
View live site
Project Type

Medical center website (publicly live).

Problem

A center offering many dental services around the clock needs visitors to see what it offers and reach it quickly — by phone, WhatsApp or map.

Approach

Right-to-left Arabic homepage with a service grid that links to a dedicated page for each treatment, a blog section, a separate English version, a discount-offer sign-up form with a confirmation window, a floating WhatsApp button and a map link.

Result

A static multi-page site with a service-by-service structure and several direct contact paths, published on GitHub Pages.

Maadi Foot Clinic

A foot-care clinic website in Maadi with a bold dark theme, a light-mode toggle, an Arabic/English switch, a booking form and WhatsApp contact.

Clinic Website AR / EN HTML · CSS · JS
View live site
Project Type

Clinic website (publicly live).

Problem

Patients looking for specialized foot care need to find services, working hours and a way to book without hunting through the page.

Approach

A dark, high-contrast design with a teal accent, a light/dark theme toggle and an Arabic/English switch. The hero puts booking and WhatsApp first, working hours and location sit in a visible bar, and a booking form collects name, phone, service and date.

Result

A single-page clinic site organized into about, services, doctors, booking and contact sections.

Technologies

HTML · CSS · JavaScript · Hosted on Vercel
